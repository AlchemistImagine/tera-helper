## 🧩 About

**TERA Helper** is a comprehensive overlay menu for TERA on Windows featuring player ESP, cooldown tracker, loot radar, teleport, no-animation, and a configurable HUD.

Based on popular overlay tools and community mod menus.

---

## ✨ Features

### 🎮 Core Tools
- Player ESP — highlight enemies, allies, and NPCs through walls
- Cooldown Tracker — overlay skill cooldowns in real time
- Loot Radar — mark nearby drops and gathering nodes
- Teleport — move to saved waypoints and coordinates
- No-Animation — skip cast animations for faster skill chaining

### 🎨 Interface & HUD
- Overlay Menu — toggle with a hotkey, fully resizable
- Custom HUD — show HP, MP, and stamina bars anywhere
- Config Profiles — save and load settings per character

### 🏋️ Utility & Training
- Waypoint Manager — store and cycle through map points
- Damage Log — review incoming and outgoing hits
- Auto-Loot — pick up nearby drops automatically
- Safe Mode — disable risky features on official servers
